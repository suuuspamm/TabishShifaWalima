# Tabish & Shifa — Dawat-e-Walima Invitation

A standalone Walima-only version of the wedding invitation website. It keeps the envelope opening, invitation reveal, scratch-to-reveal date card, countdown, calendar download and venue map link.

## Event
- Dawat-e-Walima: 26 December 2026, 7:00 PM
- Venue: Alpa Bachat Sanskrutik Bhavan, Queens Garden, Camp, Pune – 411001
- Groom: Tabish Farooque Peerzada
- Bride: Shifa Riyazahmed Peerzade
- Groom's parents: Late Mr. Farooque Peerzada & Mrs. Nilofer Peerzada

## Files
- `index.html` — invitation content
- `styles.css` — Royal Plum & Rose Gold theme
- `script.js` — envelope, scratch card, countdown and Walima calendar event

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.
